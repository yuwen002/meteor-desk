# MeteorDesk 使用手册

## 1. 产品说明

MeteorDesk 是一个本机运行的开发与运维桌面工作台，包含日志分析、本地服务管理和开发工具箱。日志内容、服务配置和转换操作默认在本机处理；应用不提供远程 HTTP 服务，也不会自动上传日志。

## 2. 启动与构建

### 开发环境

需要 Go 1.23 或更高版本、Node.js 22（或兼容的 LTS）、npm、Wails v2 及当前操作系统所需的桌面开发依赖。安装 Wails 依赖的方法请参考 [Wails v2 安装说明](https://wails.io/docs/gettingstarted/installation)。

在仓库根目录运行：

```bash
cd frontend
npm install
npm run build
cd ..
go mod tidy
go test ./...
wails dev
```

### 构建桌面程序

```bash
cd frontend
npm install
npm run build
cd ..
wails build
```

CI 会额外在 Ubuntu、Windows 和 macOS 上执行单元测试与桌面构建；通过 CI 不等于已经完成所有操作系统上的实机交互测试。

## 3. 日志分析

1. 打开“日志分析”，点“选择文件”，或把日志文件拖入应用。
2. 输入关键字后检索。默认按普通文本匹配；开启正则后按整行执行 Go 正则表达式。
3. 选择上下文行数（0、2、5、10）和结果上限，再开始检索。
4. 扫描期间可查看进度和逐步出现的匹配结果；点取消会停止后续扫描，并保留已经发现的结果。
5. 选择结果可查看行号、前后文以及 JSON/NDJSON 内容。JSON 字段面板支持按字段路径或字段值筛选。

### 搜索限制

- 单次最多返回 5,000 条匹配结果。
- 普通文本按固定缓冲区扫描，可匹配跨缓冲区边界的关键字；显示内容仅为有限预览。
- 每条结果的内容预览最多 8 KiB；前后文单行最多显示 1 KiB。
- 正则模式按整行匹配，单行超过 4 MiB 会停止并提示改用普通文本搜索。
- 路径、查询条件、上下文数量和结果上限会参与本地检索历史或偏好保存。

## 4. 本地服务管理

### 创建服务

1. 打开“进程管理”，点击“新建服务”。
2. 填写名称、可执行文件、参数、工作目录和需要覆盖的环境变量。
3. 参数必须使用 JSON 字符串数组，例如 `["run", "./cmd/server"]`；不要把整行命令写成一段 Shell 字符串。
4. 保存后，服务只会记录配置，不会自动执行命令。

可执行文件示例：

- Go：可执行文件为 `go`，参数为 `["run", "."]`。
- Node.js：可执行文件为 `npm`，参数为 `["run", "dev"]`。
- 自编译程序：优先填写可执行文件的绝对路径，并设置正确的工作目录。

### 启动、停止和依赖

- 单个服务可启动、停止或重启。
- “全部启动”会按依赖拓扑顺序启动；“全部停止”会先停止依赖方。
- 在“启动前置依赖”中选择依赖项。循环依赖会被拒绝。
- 服务输出分为标准输出、标准错误和系统消息。每个服务最多缓存 1,500 行，每行最多保存 64 KiB。
- 服务状态会记录 PID、退出码、退出原因、开始/结束时间和本次运行时长。

### 环境变量和配置迁移

- 环境变量预览默认会遮蔽疑似密码、Token、密钥和凭据等敏感值。
- 脱敏导出会将识别为敏感的环境变量值清空；完整导出会包含真实值，必须妥善保存。
- 导入配置会生成新的服务 ID，并重新映射导入文件内部的依赖关系；不覆盖既有配置，也不会自动启动。
- 为安全起见，导入后请检查可执行文件、工作目录、参数和被脱敏的环境变量。

## 5. 开发工具箱

开发工具箱提供时间戳/时区转换、JSON 格式化和结构化比较、UTF-8 Base64、JWT 载荷解码、URL 与查询参数处理。转换在本机完成。

JWT 工具只解码 Header 和 Payload，不验证签名，因此不能据此认定令牌可信。不要将私钥、生产密码或敏感 Token 粘贴到不可信环境。

## 6. 本地数据和隐私

应用偏好和服务配置保存在当前用户系统配置目录下的 `MeteorDesk` 子目录：

- `settings.json`：最近文件、搜索历史、上下文行数和结果上限。
- `processes.json`：服务配置，包括可能含有敏感信息的环境变量。

导出文件由用户自行选择保存位置。请限制完整导出文件的访问权限，不要将其提交到公共代码仓库。

## 7. 常见问题

**无法打开文件选择器或提示桌面桥接不可用**

请从 Wails 桌面程序启动，而不是直接在浏览器打开前端页面。确认已经执行 `wails dev`，并检查启动日志。

**正则搜索因长行失败**

正则需要将单行累积后再匹配。对大于 4 MiB 的日志行，请尝试普通文本搜索。

**服务启动后立刻显示异常退出**

在服务列表查看退出原因，并在右侧查看退出码和错误详情。检查可执行文件是否存在、参数 JSON 是否有效、工作目录是否正确，以及服务依赖或环境变量是否齐全。

**停止服务后仍有子进程**

MeteorDesk 会尝试按操作系统终止进程树，但操作系统和子进程的行为存在差异。请核对 PID、子进程以及输出日志；重要服务应在目标系统上实测启停流程。

## 8. 快捷键

- Ctrl/⌘ + O：选择日志文件。
- Ctrl/⌘ + K：切换到日志分析并聚焦搜索框。
- Ctrl/⌘ + Enter：执行检索。
- Ctrl/⌘ + 1 / 2 / 3：切换日志分析、进程管理和开发工具箱。
