# MeteorDesk 项目路线图

路线图以可用的最小版本为优先，先打磨关键工作流，再逐步扩展功能。

## 阶段 0：工程基础

- [x] 初始化 Wails v2 与 Go 模块。
- [x] 接入 Vue 3、TypeScript 和 Vite。
- [x] 建立暗色桌面工作台与中文导航。
- [x] 实现原生文件选择和基础日志检索。
- [x] 增加检索任务进度、取消接口及单元测试。
- [ ] 在 Windows、macOS、Linux 上完成真实桌面构建验证。
- [x] 建立自动化检查流程（Go 测试、前端类型检查、构建和基础性能基准）。

## 阶段 1：日志分析

- [x] 通过系统文件选择器打开日志。
- [x] 普通文本检索与 Go 正则表达式检索。
- [x] 返回行号，并限制结果数量和预览长度。
- [x] 普通文本关键字跨读取缓冲区边界匹配。
- [x] 进度查询和取消任务的后端机制。
- [x] 对正则模式设置单行大小上限，保护内存。
- [ ] 在真实桌面界面验证进度条和取消操作。
- [ ] 增加检索耗时统计、进度状态和异常恢复体验。
- [x] 增加上下文行（0、2、5、10 行）。
- [x] 增加固定行高的虚拟结果列表。
- [x] 增加 JSON / NDJSON 行格式化预览与字段路径/值筛选。
- [x] 增加最近文件、检索历史和偏好设置持久化。
- [x] 增加 64 MiB 大文件基准，可按环境变量提高到约 1 GiB。
- [ ] 增加增量结果事件，避免等待检索结束后才显示首批结果。
- [ ] 补充文件编码识别和更大文件的性能记录。

- [ ] 时间戳与时区转换。

## 工程原则

- 默认本地运行，不默认启用遥测。
- 不为了搜索而一次性读取完整日志文件。
- 限制结果数量和单条预览长度。
- 耗时任务必须能够查询进度并取消。
- 不默认将任意命令字符串当作 Shell 脚本执行。
- 不向远程服务发送日志内容。
- 如有操作系统差异，应在实现和文档中明确说明。
