# MeteorDesk 项目路线图

## 阶段 0：工程基础

- [x] 初始化 Wails v2、Go 和 Vue 3 + TypeScript + Vite。
- [x] 建立暗色中文工作台。
- [x] 配置 GitHub Actions：Go 测试、性能基准和前端构建。
- [ ] 在 Windows、macOS、Linux 完成桌面程序实机验证。

## 阶段 1：日志分析

- [x] 原生文件选择与拖放文件打开。
- [x] 普通文本和 Go 正则表达式检索。
- [x] 固定大小缓冲区读取、跨块关键字匹配和有限结果预览。
- [x] 检索进度、取消机制和进度条。
- [x] 前后 0、2、5、10 行上下文。
- [x] 结果虚拟滚动。
- [x] JSON/NDJSON 行格式化和字段路径/字段值筛选。
- [x] 上一条/下一条匹配导航。
- [x] 64 MiB 合成日志基准，可配置扩大到约 1 GiB。
- [ ] 增量结果事件，减少等待完整扫描结束才显示结果的延迟。
- [ ] 补充常见编码识别、真实日志基准和吞吐量记录。
- [ ] 更细致的复杂 JSON 类型和多行 JSON 支持。

## 阶段 2：本地进程管理

- [x] 保存服务名称、可执行文件、参数、工作目录和环境变量。
- [x] 将进程配置持久化到本机。
- [x] 启动、停止、重启并展示状态与 PID。
- [x] 采集标准输出、标准错误与系统状态消息。
- [x] 限制进程输出单行大小和历史缓存行数。
- [ ] 支持批量启动、批量停止和服务依赖顺序。
- [ ] 完善各操作系统的优雅退出、进程树回收和退出码展示。
- [ ] 为敏感环境变量添加界面遮蔽功能。

## 阶段 3：桌面体验与配置

- [x] 最近打开文件与检索历史。
- [x] 记住上下文行数和结果上限。
- [x] Ctrl/⌘+O、Ctrl/⌘+K、Ctrl/⌘+Enter、Ctrl/⌘+1/2/3 快捷键。
- [ ] 可编辑快捷键配置。
- [ ] 导入/导出服务配置，并支持脱敏导出。
- [ ] 主题设置与更完善的窗口布局适配。

## 阶段 4：开发工具箱

- [ ] 时间戳与时区转换。
- [ ] JSON 格式化、压缩和对比。
- [ ] Base64 编码与解码。
- [ ] JWT 载荷查看，并明确说明不验证签名。
- [ ] URL 与查询字符串处理。

## 工程原则

- 默认本地运行，不默认启用遥测，不上传日志内容。
- 不为了文本检索而拼接整条超长日志。
- 限制结果、预览和进程输出缓存。
- 长任务应支持进度查询与取消。
- 不默认将任意命令字符串当作 Shell 脚本执行。
- 平台差异应通过测试和文档明确说明。
