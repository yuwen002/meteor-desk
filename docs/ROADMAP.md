## 阶段 1：日志分析

- [x] 原生文件选择与拖放文件打开。
- [x] 普通文本和 Go 正则表达式检索。
- [x] 固定大小缓冲区读取、跨块关键字匹配和有限结果预览。
- [x] 检索进度、取消机制和进度条。
- [x] 前后 0、2、5、10 行上下文。
- [x] 结果虚拟滚动。
- [x] JSON/NDJSON 行格式化和字段路径/字段值筛选。
- [x] 上一条/下一条匹配导航。
- [x] GB 级合成日志全量扫描基准（CI 默认约 1 GiB），可通过环境变量调整大小。
- [x] 搜索扫描期间按游标增量提供新匹配，前端逐步展示并支持取消。
- [x] 增量结果事件（Wails `log-search:update` 推送），轮询接口保留为兼容回退，并通过任务 ID/共享游标避免重复追加。
- [x] 自动识别 UTF-8/UTF-16 BOM、常见无 BOM UTF-16 与 GB18030 回退，并允许手动选择编码。
- [x] 提供可选本机真实日志基准（不上传日志），并文档化吞吐量、分配量与测试环境记录方法。
- [x] JSON 字段路径支持含点号、空格、括号、空键和 Unicode 的特殊键，并增加单元测试。
- [x] 可选多行 JSON 文档检索：按括号深度识别对象/数组，字符串转义不误判，普通日志行仍可检索；单文档限制 4 MiB。
- [x] 可选时间戳事件聚合：按行首时间戳聚合事件与异常堆栈，命中详情返回完整事件（单事件 512 KiB）。
- [x] 可配置事件边界规则（时间戳、空行或自定义正则），空行分隔符不写入事件；多行 JSON 命中返回完整文档上下文（单条 512 KiB，单次 32 MiB 预算）。
- [x] 检索结果导出 CSV/JSON（含上下文与事件/文档内容，CSV 带 BOM，单次上限 32 MiB）；导出范围跟随当前过滤与排序。
- [x] 实时跟踪：按字节偏移增量读取新增完整行，每秒刷新、保留最近 1,000 行并可跟随滚动，文件截断时自动重置。
- [x] 命中高亮、结果内内容/行号过滤、行号升序/降序切换，以及按文件收藏关键行（本机 localStorage，上限 500 条）。
- [x] 检索结果聚合统计：按日志级别统计数量与行号范围，按错误签名汇总 Top 5，可复制纯文本排查摘要。
- [x] 错误时间分布：把 error/warn 行按时间戳分桶（1 秒至 1 天自适应、最多 24 格）并绘制堆叠柱状图，无时间戳的行单独计数。
- [x] 时间格联动过滤：点击时间格把结果限定到该时段，工具栏保留可清除的时段标识，柱状图在筛选时仍保留全貌。

## 阶段 2：本地进程管理

- [x] 保存服务名称、可执行文件、参数、工作目录和环境变量。
- [x] 将进程配置持久化到本机。
- [x] 启动、停止、重启并展示状态与 PID。
- [x] 采集标准输出、标准错误与系统状态消息。
- [x] 限制进程输出单行大小和历史缓存行数。
- [x] 应用退出时取消检索任务，并尝试停止当前工作台启动的服务。
- [x] 支持批量启动、批量停止和服务依赖顺序。
- [x] 拒绝无效依赖和循环依赖；启动按拓扑顺序执行，停止按反向顺序执行。
- [x] Linux/macOS 按进程组发出 SIGTERM，超时后 SIGKILL；Windows 使用 taskkill /T 与强制结束回退，并补充父子进程测试。
- [x] 记录并展示常规进程退出码（信号终止时可能没有常规退出码）。
- [x] 记录并显示进程启动时间、结束时间和本次运行时长。
- [x] 区分正常退出、非零退出、Unix 信号终止、手动停止和启动失败，并在服务列表显示退出原因与失败摘要。
- [x] 为启动失败补充可操作的诊断提示，并测试可执行文件缺失和工作目录不存在场景。
- [x] 加固并发启停、停止后立即重启和输出管道异常未关闭时的退出收尾；继续进行平台实机验证。
- [x] 默认遮蔽敏感环境变量，并在脱敏导出时清空可疑敏感值。
- [x] 异常退出自动重启：`on-failure` 策略、1 秒起步到 30 秒的指数退避、1–20 次上限，手动停止/改配置/删除时取消待执行重启。
- [x] TCP/HTTP 健康检查：间隔、超时与失败阈值可配，状态与诊断信息同步到界面与运行输出；探测失败不直接触发重启。
- [x] 依赖就绪门槛：上游配置健康检查时可设置就绪等待（0–600 秒），未通过则跳过下游并写明原因。
- [x] 进程资源监控：后台每 2 秒采样 CPU 与内存，列表和详情展示，停止后清空。
- [x] 进程资源历史：保留最近 5 分钟采样点（最多 150 个），在详情绘制 CPU/内存曲线并标注峰值与内存变化量。
- [x] 端口诊断：可声明监听端口，启动时提示冲突，详情面板展示配置端口状态与本服务实际监听端口。
- [x] 生命周期时间线：记录启动、就绪（含启动耗时）、自动重启与退出事件，跨重启保留最近 40 条，进程退出后仍可回看。
- [x] 依赖关系图：按最长路径分层绘制服务依赖与启动顺序，节点跟随运行状态配色，循环依赖用虚线标出。

## 阶段 4：开发工具箱

- [x] 时间戳与时区转换。
- [x] JSON 格式化、压缩和结构化字段对比。
- [x] Base64 编码与解码（UTF-8）。
- [x] JWT Header/Payload 查看和 exp 过期提示，并明确不验证签名。
- [x] URL 与查询字符串解析、组件编码和解码。
- [x] HTTP 调试器：显式发送常用方法请求，查看状态、响应头、正文、耗时与接收字节数；请求/响应正文各限制 2 MiB，可配置超时（默认 30 秒、上限 120 秒）、重定向跟随与 TLS 校验跳过，并保留最近 10 条本机请求历史。
- [x] HTTP 调试器 cURL 互转：粘贴 cURL 命令回填表单，或把当前请求生成可复制的多行命令。
- [x] Cron 表达式解析：标准五段（分 时 日 月 周）逐段语义说明，按本机时区列出接下来 8 个执行时间；未来五年无命中时明确提示而不是静默返回空列表。
- [x] 文本差异比较：按行对比两段文本并以 +／- 标记新增与删除，两侧合计超过 2,000 行时拒绝并提示上限。
- [x] 日志脱敏：把 JSON 字段、键值对、`Authorization`、URL 查询参数与私钥块里的敏感值替换为占位符并统计替换次数，全部在本机内存完成。
- [x] 哈希摘要与 HMAC：同时计算 SHA-1/256/384/512 四个摘要，以及 HMAC-SHA256/384/512；基于浏览器原生 `crypto.subtle`，密钥以 password 输入不回显。
- [x] 随机字符串与 UUID v4：按长度与字符类生成加密安全随机串（`crypto.getRandomValues` + 拒绝采样），附独立的 UUID v4 生成器；不使用 `Math.random`。
- [x] 正则表达式调试：实时展示匹配数、命中位置、捕获分组与耗时，强制 global，零长度匹配自增防死循环，单次 10 万命中封顶。

## 阶段 5：模块协同与运行数据持久化

- [x] 服务输出落盘：可为单个服务开启把标准输出/标准错误写入配置目录 `logs/<服务名>.log`，单文件上限 64 MiB，超出后轮转并最多保留 3 份，详情面板显示当前落盘路径。
- [x] 落盘输出接入实时跟踪：对开启落盘的服务直接复用 `ReadLogTail` 的偏移增量读取，无需等待日志分析手动选文件。
- [x] 跨模块跳转：进程详情可一键把输出文件加载到日志分析（沿用当前文件、检索参数与编码模式），日志分析可按文件路径反查它属于哪个已配置服务并跳到该服务。
- [x] 生命周期时间线持久化：按服务把最近 200 条事件写入配置目录 `process-events.json`，应用重启后仍可回看，删除服务时一并清理对应记录。
- [x] 运行历史：记录每次运行的起止时间、退出原因与退出码、自动重启次数、峰值 CPU 与内存，本机保留最近 100 次并在详情展示。
- [x] 服务分组（场景）：把若干服务命名成一组并可一键按依赖顺序整组启停，分组只引用服务配置、删除分组不影响服务本身；分组配置与进程配置同目录持久化。
- [x] 端口占用可操作：诊断出端口被其他进程占用时展示占用者 PID 与进程名，仅当该进程是本工作台启动的服务时提供停止入口，否则只提示不终止。
- [x] 落盘、时间线与运行历史的写入串行化并在退出时同步落盘，避免并发追加产生半行或乱序；补齐落盘轮转、跨重启累积与并发写的后端回归测试。
- [x] 为新增桥接方法补充注释与接口文档，并覆盖跨模块跳转、分组启停与时间线回看的前端组件测试。

## 阶段 6：大规模日志检索扩展

- [x] 目录与多文件检索：按目录或通配模式选择最多 200 个文件统一检索，结果标注来源文件并可按文件分组查看，不影响单文件既有行为。
- [x] 多文件进度与取消：按文件粒度上报扫描进度与已处理字节数，取消时保留已完成文件的结果，失败文件单独列出原因。
- [x] 跨文件聚合统计：级别分布、错误签名 Top 5 与错误时间分布覆盖多文件结果合并计算，时间分桶仍按 UTC 与 24 格上限。
- [x] 绝对时间窗检索：检索参数支持起止时间（可选本地时区与 UTC），只返回行首时间戳落在区间内的命中；启用时间窗时无时间戳的行明确提示不计入结果。
- [x] 相对时间窗快捷项（最近 5/30 分钟、1/6/24 小时），与点击时间格产生的时段过滤互不覆盖，工具栏统一展示可清除的时间条件。
- [x] 结果达到上限后可续扫：保留“已截断”标记与最后处理位置，点击“从这里继续”只扫描剩余区间，不重复读取已完成部分，也不丢弃已有结果。
- [x] 结构化字段分布：对 JSON/NDJSON 日志按选定字段统计取值分布（Top 20 加“其他”），点击某个取值即可把结果过滤到该值，形成 facets 式排查路径。
- [x] 字段趋势：把选定字段的数值按自适应时间桶汇总绘制趋势，复用时间分布的步长与格数上限，无该字段或无数值的行不参与。
- [x] 命名检索式：把关键字/正则、编码、上下文、事件边界与时间窗组合保存为命名查询（本机 localStorage，上限 100 条），可一键应用、覆盖更新与删除。
- [x] 两份日志对比：选择两个本机文件做逐行差异并标出仅出现在一侧的 error/warn 行，复用现有 `textDiff` 纯函数，单侧读取上限 4 MiB。
- [x] 增加多文件目录扫描基准与并发数据竞争回归测试，并在性能指南中记录目录规模、文件数量与吞吐量。
- [x] 日志索引缓存：同一文件在大小与修改时间未变时复用上次编码检测结果，跳过重复读取 64 KiB 样本与启发式探测；缓存最多 50 个文件、24 小时过期、LRU 淘汰，原子落盘到配置目录 `file-indexes.json`，应用启动预热、退出时回写，自动识别模式下重复检索大文件更快。

## 工程原则

- 默认本地运行，不默认启用遥测，不上传日志内容。
- 不为了文本检索而拼接整条超长日志。
- 限制结果、预览和进程输出缓存。
- 长任务应支持进度查询与取消。
- 不默认将任意命令字符串当作 Shell 脚本执行。
- 平台差异应通过测试和文档明确说明。
