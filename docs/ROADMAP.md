- [x] CI 在 Ubuntu、Windows、macOS 上分别构建桌面程序。
- [ ] 在 Windows、macOS、Linux 完成桌面程序实机验证。

## 阶段 1：日志分析

- [x] 原生文件选择与拖放文件打开。
- [x] 普通文本和 Go 正则表达式检索。
- [x] 固定大小缓冲区读取、跨块关键字匹配和有限结果预览。
- [x] 检索进度、取消机制和进度条。
- [x] 前后 0、2、5、10 行上下文。
- [x] 结果虚拟滚动。
- [x] JSON/NDJSON 行格式化和字段路径/字段值筛选。
- [x] 上一条/下一条匹配导航。
- [x] GB 级合成日志全量扫描基准（CI 默认约 1 GiB），可通过环境变量调整大小。
- [x] 搜索扫描期间按游标增量提供新匹配，前端逐步展示并支持取消。

- [x] 提供可选本机真实日志基准（不上传日志），并文档化吞吐量、分配量与测试环境记录方法。
- [ ] 更细致的复杂 JSON 类型和多行 JSON 支持。

## 阶段 2：本地进程管理

- [x] 保存服务名称、可执行文件、参数、工作目录和环境变量。
- [x] 将进程配置持久化到本机。
- [x] 启动、停止、重启并展示状态与 PID。
- [x] 采集标准输出、标准错误与系统状态消息。
- [x] 限制进程输出单行大小和历史缓存行数。
- [x] 应用退出时取消检索任务，并尝试停止当前工作台启动的服务。
- [x] 支持批量启动、批量停止和服务依赖顺序。
- [x] 拒绝无效依赖和循环依赖；启动按拓扑顺序执行，停止按反向顺序执行。
- [x] Linux/macOS 按进程组发出 SIGTERM，超时后 SIGKILL；Windows 使用 taskkill /T 与强制结束回退，并补充父子进程测试。
- [x] 记录并展示常规进程退出码（信号终止时可能没有常规退出码）。
- [x] 记录并显示进程启动时间、结束时间和本次运行时长。
- [x] 区分正常退出、非零退出、Unix 信号终止、手动停止和启动失败，并在服务列表显示退出原因与失败摘要。
- [x] 为启动失败补充可操作的诊断提示，并测试可执行文件缺失和工作目录不存在场景。
- [x] 加固并发启停、停止后立即重启和输出管道异常未关闭时的退出收尾；继续进行平台实机验证。
- [x] 默认遮蔽敏感环境变量，并在脱敏导出时清空可疑敏感值。

## 工程原则

- 默认本地运行，不默认启用遥测，不上传日志内容。
- 不为了文本检索而拼接整条超长日志。
- 限制结果、预览和进程输出缓存。
- 长任务应支持进度查询与取消。
- 不默认将任意命令字符串当作 Shell 脚本执行。
- 平台差异应通过测试和文档明确说明。
